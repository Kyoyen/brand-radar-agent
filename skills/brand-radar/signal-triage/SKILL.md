# 信号初筛

只回答一个问题：这条信号值不值得继续查，而不是急着把它写成企划结论。

先核对材料的来源、日期、地区、版本和与本周目标的关系。再从时间窗口、可行动性、证据充分度与品牌安全风险判断，归入以下一种处理建议：

- 本周跟进：时间临近、与任务直接相关，且有足够材料支持继续形成企划动作。
- 继续观察：方向可能相关，但窗口尚早、影响未明或还缺关键材料。
- 主动避开：与敏感日期、品牌安全、执行冲突或明显不当联想有关。
- 信息不完整：来源、版本、日期或核心事实不足；明确写出还缺什么。

不要把转载数量当作重要性，也不要把单条材料的推测扩写成事实。相同事件先合并，过期、已替换或冲突未解的材料不能支撑确定结论。
