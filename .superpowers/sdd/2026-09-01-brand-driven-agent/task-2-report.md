# Task 2 报告：品牌档案与六问状态机

完成时间：2026-09-01

## 完成内容

- 新增仓库通用 `BRAND.md`：六个完整章节提供可复查的通用默认判断，供没有本机档案的首次使用者采用。
- 新增 `framework/brand_profile.py`：提供显式路径、本机档案、仓库默认档案的固定加载顺序；返回模式、路径、回答数与 SHA-256 指纹。
- 新增与终端 I/O 分离的 `BrandInterview` 六问状态机：逐题推进，后题引用前题答案；空行、`skip`、`跳过` 保留已有值或采用默认值；无论回答情况都能渲染完整六章节 Markdown。
- 本机档案只在六题完成、用户在 CLI 确认且本轮有新回答时原子写到被忽略的 `memory/brand/BRAND.md`；全跳过不会创建该文件，异常路径也会清理 `.tmp` 文件。
- 新增 `--brand-setup`。该入口在 `check_env()` 前处理，不调用模型，且不能与周企划或其他运行命令组合。
- 新增 `agent/AGENTS.md`，记录单 Agent 的材料、调查、证据和人工确认边界。
