## iPhone 无限画布 MVP

原生 SwiftUI / UIKit 画布支持自由拖放、双指缩放、查看全貌、六套模板、语义连线与关系编辑、本机保存、选卡改稿、放下与恢复、旧稿和系统分享。日常 Brief 接受文字或完整口述，继续生成与连接节点；实时语音独立为「边说边画 · Beta」，稳定片段流式成图，松手后选择保留或放弃，上滑撤回本段。主界面直接使用当前画布；示例收进设置，与真实作品分别保存。Brief 底部按住听写、松手进入可编辑草稿，确认发送后整理；Beta 单独显示聆听转写和变化数量，聊天左右区分说话者。Agent 支持分组包含、分支连线；分组标题可拖动整组和双击聚焦。实操可在手机填写 HTTPS API 地址、模型和 Key（支持函数工具调用的 Chat Completions），或使用局域网 Mac 的单 Agent。API Key 与 Mac 配对码分别保存在本机 Keychain。这台个人 iPhone 已通过部署时的一次性配置导入直接连接现有 DeepSeek，临时凭据文件已删除，更新无需重新填 Key。直连没有外部调查工具，不把创意当成已查证事实。

安装前补充了失败 Brief 重试、未发送文字保存、画布重命名、拖卡时延后自动缩放和远距离全貌适配。演示语音要求系统设备端识别；设备不支持时提示改用键盘或预设按钮。Release 使用尺寸优化和符号剥离，不打包模型与第三方 Swift 依赖。

后端补充任务 `edges` 与原子卡片/连线更新，默认本机服务行为保持；显式 `python -m studio.server --phone` 才开放局域网，并要求 bearer 配对码。真实模型已完成一次 3 卡 / 2 关系生成和随后选卡改稿，验证 ID、位置、采用状态、无关卡、关系与旧稿保留。具体使用和验证边界见 [iPhone 说明](../ios/README.md)。

## 这次实际运行中的改进

使用本机已配置的 DeepSeek `deepseek-v4-flash` 跑过完整研究与多轮改稿，实际打开案例之外的瑞幸官方介绍页，并关联到作品。选中原有创意继续改写后，卡片 ID、位置和保留状态保持，旧文字进入修改历史。

第一轮作品暴露了两个问题：把路线点位与距离误读成人的停顿行为；为了写得像成品而编造长椅、树荫或步行时长。已据此重写品牌判断和 Brief 方法，要求事实、解释和创意假设分清，不让免责声明代替真实依据。作品仍需要人的眼光，这些方法不等于输出质量保证。

另一个真实交互问题是“保留”被误当成冻结文字，导致 Agent 反复被拒后另建重复草稿。已撤去这道限制：保留代表选定方向，仍可按本次要求继续改文字；人的位置、状态和旧稿由保存层负责。新一轮已实际改写成功。

专业方法现在每轮从 `agent/AGENTS.md` 与三个简短营销技能读取。后续发现判断问题时，可以直接改善这些方法，不必先扩建运行框架。

## 运行与开发

按 [README](../README.md) 安装 `requirements.txt`、构建 `web/`，在本机 `.env` 配置真实模型，然后运行：

```bash
.venv/bin/python run.py --studio
```

地址为 `http://127.0.0.1:8765`。任务存于已忽略的 `outputs/studio/`；自定义品牌档案存于已忽略的 `memory/brand/BRAND.md`。保存品牌档案后，下一次调查或改稿读取新内容，已有作品不会自动重写。

新结构和工具接口见 [Agent 打造说明](product/AGENT-BUILD.md)。新增 Agent、任务保存与旧 weekly CLI 共 22 项相关检查通过，前端生产构建通过。已实际操作页面新建并调查、选卡改稿、直接编辑、保留与放下、查看旧稿、拖动后刷新和 HTML 导出；HTML / Markdown 导出均读回当前文字并排除已放下作品。390 像素窄屏检查了导航与画布，桌面仍以电脑操作为主。

真实桌面截图为 `docs/assets/brand-radar-studio.png`，记录真实模型初稿、多轮反馈和直接编辑后的协作结果，不代表模型一次生成的质量。

## 当前边界

- 面向个人本机使用，没有账户、多人同步、数据库或自动调度；只有一个产品 Agent。
- 免费公开搜索可能偏题，部分网站会限制读取。来源失败和正文截断会明确反馈；可补充公开链接或粘贴正文。
- 来源图片供人在桌面参考，Agent 当前读的是网页文字；没有图像理解、生成图片、视频或 PDF 解析。
- 有来源只证明可以追溯，不能自动证明判断成立。真实门店、受众行为和执行资源仍需具体查证。
- 本轮真实运行验证使用 DeepSeek；其他兼容模型服务保留接入，未逐个真实调用。
- 不自动发送、发布、投放或调整预算。
