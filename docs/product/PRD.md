# Brand Radar：把值得追的观察，做成值得讨论的企划

## 愿景

让品牌企划人员拥有一位持续工作的调查搭档。它会看材料、找新依据、提出不同的解释，知道什么值得留下，也能听懂人为什么不喜欢一个方案。

产品的中心是一次合作：人指着某个观察说“这个有意思，沿着它继续”，Agent 就在同一份作品上推进；人指出现实条件不成立，方案的做法随之改变。

## 为谁，在什么时候

品牌方和代理公司的营销企划人员，在创意会前、准备一项小企划时，或已有初稿但缺少有说服力的角度时使用。最初围绕瑞幸咖啡、现制咖啡、全国与上海展开。

用户可以带着明确问题来，也可以只有几份材料。Agent 应帮助发现值得决定的问题，不要求用户先完成一份需求问卷。

## 当前贯穿案例

**上海周末，咖啡该出现在什么时候？**

以公开的城市漫步路线、瑞幸品牌与自提模式、星巴克兴趣社区服务为起点，寻找一个轻量内容方向。此次独立研究不上新品、不新增折扣、不组织线下活动，也不把门店适合久坐当成前提。

这里存在值得研究的张力：完整旅游路线与短暂日常片段、集合停留与随取随走、城市内容与品牌参与资格。资料提供起点，不预先规定结论。

## 一次工作

1. 从问题或研究起点新建企划。已有品牌底稿可以沿用，空白也能开始。
2. 把链接、摘录或文本文件放上桌面。原始出处与日期跟着材料走。
3. Agent 按问题阅读、查找、比较，逐渐留下值得看的观察、创意与疑问。
4. 用户打开依据、移动卡片、直接改字，或选择“保留”“放下”。选中卡片追问时，Agent 继续改这件作品。
5. 关闭后可以从历史继续。需要带进会议时，导出当前工作稿与来源。

## 它应该有什么眼光

- 看具体的人和行为：从出发、经过、等待、停下等时刻观察，而不只摘录热词和节点。
- 看品牌参与的理由：清楚品牌实际能提供什么，不把公共事件改写成品牌合作。
- 看创意的作用方式：不同方向应在行为、载体、参与方式或激励上不同。
- 看反例：认真处理能推翻当前想法的事实，不让所有材料都变成对原方案的支持。
- 会取舍：允许一个好方向，也允许暂时没有机会。日历、关键词和 Brief 按需出现。

## 企划桌面

暖白桌面、墨绿侧栏、有轻微纸张层次的卡片。主位置给观察和正在修改的作品；图片帮助理解原始场景，来源随时能展开。

桌面可以拖动、缩放、整理和聚焦。对话与卡片相连，用户不必重新解释上下文。窄窗口提供可读内容，避免强迫用户操作缩小的完整画布。

“新建、历史、品牌档案、设置”承担导航职责。首页不以配置、检查状态或工作日志为主角。

## 事实与创造力

公开材料说明发生了什么；观察表达如何理解它；创意提出可以尝试什么。创意可以尚未发生，其引用的事实仍需真实。材料没有覆盖的门店、经营数据、合作和执行资源，不能由模型补写。

研究参考图保留原始出处，不因此获得商业使用授权。品牌底稿里的编辑判断与品牌官方规范也要分清。

## 人的作用

人决定方向是否采用，补充只有业务现场知道的条件。一次否决首先改变当前方案；只有用户主动保存品牌底稿，才成为后续工作的长期取舍。

产品默认停在本地讨论与草稿，不替人发消息、发布内容、投放或改预算。

## 怎样继续打造

观察真实作品如何被修改，判断问题来自资料、品牌条件、调查动作还是创意方法，再修改对应的一小部分。当前不建设自动评分、自我改写或多角色编排平台。

下一次改进应当让一个具体企划更有用，而不是让功能清单更完整。
