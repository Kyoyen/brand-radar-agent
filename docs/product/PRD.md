# Brand Radar Demo PRD

更新日期：2026-08-31

## 产品目标

让营销企划人员输入一个品牌和品类后，在一个页面里快速看到“近期值得关注的竞品动作和营销节点”，并直接获得可继续讨论的选题角度。

第一版只需要证明这个闭环有用、能操作、能解释，不追求实时全网覆盖。

## 默认案例

- 品牌：瑞幸咖啡
- 品类：现制咖啡
- 地区：全国 + 上海
- 竞品：星巴克中国、库迪咖啡、Manner、麦咖啡
- 数据：仓库内置 Replay

## 单一用户路径

1. 用户确认品牌、品类、地区、竞品和关键词。
2. 点击“生成今日情报”。
3. 页面展示经过合并和排序的情报卡片。
4. 用户使用品牌、类型和关键词筛选。
5. 用户打开卡片查看来源，并浏览日历、热词和三个 Brief 角度。

## 页面内容

### 1. 观察设置

品牌、品类、地区、竞品和关注关键词。第一版允许使用默认值，也允许直接编辑。

### 2. 情报流

一张卡片代表一个营销事件，而不是一条转载链接。卡片显示：

- 标题与一句话摘要
- 涉及品牌和事件类型
- 为什么值得关注
- 日期与地区
- 来源名称、链接和 `REPLAY` 标识

### 3. 营销日历

展示未来 30 天的节日、消费节点、地区活动和敏感日期。点击日期可以过滤情报流。

### 4. 热门关键词

展示当前数据中的重点词。点击关键词可以过滤情报流。

### 5. Brief 建议

根据当前筛选结果给出三个角度，每个角度包含：机会点、为什么是现在、关联情报卡片和一个风险提醒。

## Agent 的最小职责

- 合并明显属于同一 Campaign 的材料。
- 按品牌相关性、时间和事件类型排序。
- 用营销企划语言解释“为什么现在值得看”。
- 生成 Brief 时只引用页面中存在的情报卡片。
- 证据不足或涉及敏感日期时标记“待核”。

第一版可以用简单规则和固定 Replay 完成这些行为；接入模型不是 Demo 上线的前置条件。

## 第一版必须完成

- 一个无需 API Key 即可打开的 Dashboard。
- 一套围绕瑞幸和咖啡竞品的 Replay 数据。
- 可编辑的观察设置和三个基础筛选条件。
- 情报流、日历、关键词和三个 Brief 角度。
- 每张卡片可以查看来源，Replay 标识始终可见。

## 暂不进入第一版

- 自动发现全网竞品和大规模实时抓取。
- 多 Agent、向量数据库、复杂工作流引擎和模型微调。
- 登录、权限、云部署、数据库和定时任务。
- 自动发稿、自动投放或法律合规结论。
- 完整评测平台、Prompt 版本管理和自我学习。

## Demo 验收

- 按 README 的一条命令可以启动或打开页面。
- 默认瑞幸案例无需配置密钥即可完整展示。
- 修改竞品、事件类型或关键词后，情报流立即变化。
- 重复材料不会占据多张主卡。
- 日历和关键词能反向筛选情报流。
- 三个 Brief 角度均引用当前可见的情报卡片。
- 新用户能在三分钟内完成“生成情报 → 找到重点 → 查看来源 → 看到 Brief”。
