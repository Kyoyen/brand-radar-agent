# 随心画板，AI 帮你落笔

2026-09-18 · 当前迭代路线

核心是可自由组织、阅读、修改和保存的画板；AI 是理解表达并操作画板的助手。用户表达一个意图，助手把它转换为有范围、可观察、可撤回的节点、内容、分组和连线操作。无需向用户解释 MCP；当前实现是原生画布与模型工具调用，并未嵌入外部 MCP 服务。

## 本轮落实

此前 B01/B02 已补齐编辑提交和放下恢复，主要影响可靠性。本轮继续评议 B03–B10，集中完成可感知的工作闭环：

1. 连续表达：发送后保留聊天面板；阅读历史不抢滚动；选中卡片/分组范围明确，生成过程中冻结本轮目标。普通听写先形成可编辑草稿，Beta 继续实时落图并待确认。
2. 清楚阅读：画布根据屏幕字号呈现轮廓、标题或摘要；卡片可进入完整阅读页，再继续改或编辑；共享颜色与最小点击范围。
3. 可控执行：结果提示来自实际文档变化，可定位、返回原视角、条件撤回本轮。人工后来修改优先。
4. 接续与分享：画布搜索、按最近修改排序、当前画布的已放下入口、按分组导出可阅读 Markdown，保留已有图片/PDF/可编辑包。
5. 容量与交付：真实本地存储的节点/文档/附件规模测量，相关原生与 UI 回归；同步 GitHub 与 TestFlight。测量不冒充真机 FPS 或真人长段语音验收。

## 能力边界

Brief 仍是首要入口；边说边画保留 Beta。优先完善画板内部操作，不扩展 Hermes、多人会议、外部发布/投放或账户系统。旧网页调查工作台继续保留；本轮不追求两端功能完全一致。后续以真实使用反馈决定 Agent 语义和操作精度，不堆更多入口。
