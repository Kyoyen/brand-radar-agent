## 产品锚点

Brandar 是一块随心编辑的画板。Agent 把 Brief 中可执行的意思变成看得见、改得动、撤得回的卡片、内容、分组和连线操作。“边说边画”是实时语音入口；文字 Brief 与手动编辑仍是基础。默认忠实整理，只有用户明确要求才扩展建议。用户无须理解模型或 MCP。

## 迭代顺序

### 第一站：恢复画板观感与手感

用同一台 iPhone、同一张 3/30/120 节点样本，取得缩放、拖动录屏和帧时间/内存基线。远景改为真正紧凑的卡片或结构标记，让标题在缩略形态重新排布；中景保留摘要，近景显示富内容。外框、命中范围、连线锚点共用实际尺寸，切换层级不跳。按测量结果减少手势帧内重复绘制、阴影、排版与屏外开销；“整理画布”把内容放进当前可用视口，保留人工位置；适配减少动态效果。参考历史截图恢复有价值的示例卡片设计。示例仍可离线探索，但自由输入不可再由固定脚本假装 Agent 理解了用户。统一用户可见名称 Brandar，保留原有 App 身份、个人画布和连接配置。

**通过条件：**同机前后对照不再有大空卡、闪跳和明显卡顿；示例好看且可编辑；整理后全部目标可见；报告真机帧时间和内存，而非用模拟器数据代替。

### 第二站：让文字 Brief 准确执行画布操作

先避开语音识别误差，验证“表达 → 结构化操作 → 校验 → 落图 → 实际变化提示”这一条执行路径。覆盖直白的数量指令、分支、共同依赖、分组、三幕剧本规范、选中对象补充/纠正、连线调整与删除。新增内容局部排布，不动无关卡与人工位置；歧义无法消除时简短提问。示例、真实模型和保存层共享一套操作语义，不复制假 Agent。

**通过条件：**真实 DeepSeek 在 iPhone 上完成连续任务，例如“预热、活动当天、后续三段共用一份物料；把当天改成线下”；修改原对象、不重复造卡；提示与实际变化一致；整轮可撤销/重做。

### 第三站：让“边说边画 · Beta”真正实时

接入同一执行路径。按住时以独立而轻量的聆听区显示转写，稳定语义片段排队生成；每批校验通过就更新图，显示真实的新增、修改和删减。修订号淘汰过期识别；松手补尾并提供保留/放弃，上滑撤回本段；同期人工修改优先。模型未返回有效更新时只显示真实转写和等待状态，不播放预制动画。

**通过条件：**真人真机连续口述 60–90 秒，包含停顿、改口、否定和指代，松手前看到符合语义的结构；记录首段文字、首个有效节点和末尾完成时间。断网、权限拒绝、锁屏/中断、迟到响应、待确认重开均不造成重复落图或内容丢失。普通听写仍先形成可编辑草稿，Beta 才边听边改图。

### 第四站：完成日常工作稿闭环

以真实混合内容画布打磨清单、表格、图片、手绘、附件、键盘和播放器的阅读/编辑节奏；图片与手绘转图保留原件并可纠错。回归旧画布迁移、归档恢复、附件重开、长标题、大图、多轮改稿、分享和编辑包导入；导出包不含连接凭据。

**通过条件：**用户从一句 Brief 完成混合内容作品，重开继续改，导出再导入后关系、内容和附件保持；主要操作不依赖说明文字才能找到。

每站结束后同步实际代码至 GitHub、可用构建至 TestFlight，分别读回提交和构建状态，并在手机上走该站完整任务；附同机前后画面、测试范围和未解决问题。宣传截图取自通过验收的真实界面，不用脚本效果冒充产品能力。会议转写、Hermes/飞书和直接营销执行待核心画板稳定后再评估；营销发送、公开发布、投放和预算变更仍需对具体动作取得明确授权。Web 企划调查桌面继续保留。

### 随心画板，AI 帮你落笔

2026-09-18 · 当时迭代路线

核心是可自由组织、阅读、修改和保存的画板；AI 是理解表达并操作画板的助手。用户表达一个意图，助手把它转换为有范围、可观察、可撤回的节点、内容、分组和连线操作。无需向用户解释 MCP；当前实现是原生画布与模型工具调用，并未嵌入外部 MCP 服务。

## 本轮落实

此前 B01/B02 已补齐编辑提交和放下恢复，主要影响可靠性。本轮继续评议 B03–B10，集中完成可感知的工作闭环：

1. 连续表达：发送后保留聊天面板；阅读历史不抢滚动；选中卡片/分组范围明确，生成过程中冻结本轮目标。普通听写先形成可编辑草稿，Beta 继续实时落图并待确认。
2. 清楚阅读：画布根据屏幕字号呈现轮廓、标题或摘要；卡片可进入完整阅读页，再继续改或编辑；共享颜色与最小点击范围。
3. 可控执行：结果提示来自实际文档变化，可定位、返回原视角、条件撤回本轮。人工后来修改优先。
4. 接续与分享：画布搜索、按最近修改排序、当前画布的已放下入口、按分组导出可阅读 Markdown，保留已有图片/PDF/可编辑包。
5. 容量与交付：真实本地存储的节点/文档/附件规模测量，相关原生与 UI 回归；同步 GitHub 与 TestFlight。测量不冒充真机 FPS 或真人长段语音验收。

## 能力边界

Brief 仍是首要入口；边说边画保留 Beta。优先完善画板内部操作，不扩展 Hermes、多人会议、外部发布/投放或账户系统。旧网页调查工作台继续保留；本轮不追求两端功能完全一致。后续以真实使用反馈决定 Agent 语义和操作精度，不堆更多入口。
