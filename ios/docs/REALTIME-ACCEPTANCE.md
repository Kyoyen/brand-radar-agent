# 实时逻辑成图：本轮验收

日期：2026-09-12。当前为源码预览版；下面分别记录程序检查、真实模型、模拟器交互和手机状态。

## 已验证

| 层面 | 结果 |
|---|---|
| 模型协议与校验 | 70 项原协议检查、31 项流式／富内容／分组选中检查通过。网络协议测试使用 Foundation 模型替身和真实内容块类型。 |
| 实际 DeepSeek 图片请求 | `deepseek-flash` 两批输出，指定测试图的 5 个原文标签和 5 条有向关系逐一匹配。首批 3.61 秒，总计 6.35 秒。这是合成测试图的测量，不是性能承诺。 |
| 实际系统组件与文档 | 50 项自检通过，运行于模拟器内真实模型、UIKit、PDFKit、PencilKit 和文件系统。涵盖照片原件、像素上限、无缩略图时读取原笔迹、附件包往返、缺失材料、路径防护、嵌套约束和条件撤销。 |
| 实际触摸交互 | 13 个不同 UI 测试完成验证，分次运行；初次 3 个失败修复后原断言通过。包括多选、尺寸、拖组、空白处连线、回流连线、清单表格保存，以及慢速手绘／撤销重做／重开恢复。 |
| Mac 兼容 | 26 项 Studio 测试通过，覆盖存储、Agent 和真实 HTTP 手机边界。 |
| 真机部署 | 最终安装包已通过局域网无线安装；最后一次启动因手机锁屏被系统拒绝。本轮较早构建无线启动成功，手机画布文件保留。 |

关键失败与修复：双击识别曾抢占多选与连接手势，已改为单击即时选择、同一对象二次点击展开；拖动起点曾遗漏识别阈值之前的距离，现从真实落指坐标计算。PencilKit 下方工具栏曾遮挡撤销重做，已移至顶部并通过触摸测试。

模型检查曾发现省略关系标签时被旧规则错误拒绝，现允许无文字箭头，避免编造关系文案。早期图像请求还出现过多余节点；当时未记录完整内容，不能归因于已确认的同一缺陷。最终指定图任务严格通过，不代表任意图都能正确识别；生成结构仍可人工纠正。

## 尚待真人真机验收

超过一分钟的连续口述、真实收音中的权限拒绝／锁屏／来电中断，以及长段口述的实际首节点时间尚未完成。代码已实现 50 秒识别任务续接、稳定片段排队、修订取消、松手补尾与中断恢复；程序和模拟器结果不能替代真人连续口述。

本轮后续不包含会议听录、多人发言识别、回放、生成图片、Hermes 或自动外部营销动作。

## 容量与凭据

签名应用约 1.7 MB，不含本地模型或第三方 Swift 依赖。更新前该手机画布 JSON 为 22,064 字节，附件为 0 字节；以后原件、缩略图和文档按使用量独立增长，不算进安装包。

API Key 存设备 Keychain，按端点隔离；源码、截图、画布包不包含连接凭据。公开仓库只提供源码和演示内容截图，不上传个人手机文档、签名 App、配置导入文件或运行日志。

## 复验入口

构建与 Foundation 测试命令见 [iPhone 说明](../README.md)。Debug 模拟器启动参数 `--uitesting --canvas-selfcheck` 在隔离数据中运行系统自检，将结果写到 App 的 `Library/Application Support/canvas-checks.json`。UI 测试目录为 `BrandRadarUITests/`，真实个人数据不用于常规 UI 测试。


## 2026-09-13：剧本模板与直白数量指令

新增轻量 `TaskBlueprint`：支持“我想做一个电影的几段式剧本”的默认三幕，以及明确生成 N 张内容卡的数量约束。普通 Brief 保持原路径；跨语音片段使用完整指令与本段初始画布累计数量。“N 张画布”明确解释为当前文档内的 N 张内容卡，不创建或声称创建多个独立文档。

本轮 70 项原协议检查与 56 项流式／富内容／任务规范检查通过。后者包含旧画布的无关幕标题不充数、提前 complete 后补足数量、超数批次拒绝、跨片段不重复生成 N 张、保留已有附件和数量指令来源边界。

真实 `deepseek-flash` 合成任务以“我想做一个电影的几段式剧本。请直接生成3张卡片”开头，生成恰好三张新卡，含第一幕、第二幕、第三幕标题、可编辑正文块与两条顺序关系；一次有效批次，首批与总耗时均为 6.23 秒。首次请求把正文样式填写为 `emphasis=text`，本地校验拒绝；现将这个无歧义显示别名归一为 `plain`，其他未知样式仍拒绝。调整后的真实请求严格通过。忽略目录中的复验记录为 `outputs/ios/task-blueprint-live/verification.json`，不含密钥。

边界：真实请求使用生产 URLSession、工具协议和校验器，但 Radar 画布模型为 Foundation 测试替身，内容块类型使用生产代码；不替代手机界面或真人语音验证。56 项本地检查包含模拟的跨片段状态，尚未据此宣称真实连续收音中的三幕或数量指令全部通过。模板规范和一次成功作品也不保证任意剧本质量。

### 画布性能与交互

参考 [Apple 列表与表格设计](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables) 和 [Freeform 的对象操作](https://support.apple.com/en-ie/guide/iphone/iph5e1a18c04/ios)，清单使用独立 48pt 勾选区，文字点开编辑；表格强调首行表头、隔行底色和单格编辑。画布预览采用真正的网格和清单标记，最多准备 4 行、3 列，长内容在编辑页展开。

已移除拖动期间反复递归组边界、测量文字和重建不变连线的开销。视角及输入草稿更新绕开内容历史比较，并合并保存；节点、分组、连线在屏幕外均跳过绘制。明确点击整理才全局排布，按实际内容尺寸及底部面板占用适配全貌。

- 14 项相关 UI 回归通过；随后 Beta 恢复的 2 项 UI 回归再次通过。
- 75 项真实 UIKit/内容/存储自检通过，包含 Beta 待确认重启、放弃保留人工修改、中断后继续仍需确认，以及屏外绘制剔除。

- 本次 Release 签名 App **1,912,987 字节**，约 **1.91 MB**。本次设备文件读回：个人画布 JSON **29,825 字节**，附件 **0 字节**（另有116字节配置导入回执，不含Key）。无线安装成功；锁屏阻止启动，真机绘制探针未能执行。手机与 Mac 解锁后的交互检查仍是独立的待验收项。
